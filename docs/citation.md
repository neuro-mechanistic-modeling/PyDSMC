# Citation

If you use PyDSMC in your work, please cite the paper.

## Paper

**PyDSMC: Statistical Model Checking for Neural Agents Using the Gymnasium Interface**<br>
Timo P. Gros, Arnd Hartmanns, Ivo Hoese, Joshua Meyer, Nicola J. Müller, and Verena Wolf.<br>
*Quantitative Evaluation of Systems and Formal Modeling and Analysis of Timed Systems* (QEST+FORMATS),
pages 134–156, Springer Nature Switzerland, 2025.

- :material-file-document: **DOI:** [10.1007/978-3-032-05792-1_8](https://doi.org/10.1007/978-3-032-05792-1_8)
- :material-file-pdf-box: **PDF:** [woshicado.eu/publications/2025/pydsmc/PyDSMC.pdf](https://woshicado.eu/publications/2025/pydsmc/PyDSMC.pdf)

PyDSMC builds on [Deep Statistical Model Checking](https://doi.org/10.1007/978-3-030-50086-3_6) (Gros et al., 2020).
